# 需求对齐文档 (ALIGNMENT)

## 项目定位
面向中小电商商家的自助经营数据分析智能体，以 Electron 桌面应用形式交付。

## 需求边界

### MVP 范围
- CSV/Excel 文件上传，自动解析入库
- 自然语言对话式数据分析（经营概览 + 商品分析）
- 三大分析工具：数据查询、统计分析、图表生成
- LangGraph Agent 四大能力：自我规划、工具调用、反思纠错、人类干预
- WebSocket 实时对话 + REST API 双通道
- Windows 桌面应用打包（PyInstaller + Electron）

### 二期范围
- 平台 API 对接（淘宝/京东/抖音等）
- 客户分析（RFM、复购率、流失预警）
- macOS 适配
- 多数据源关联分析

### 三期范围（进阶开发）
- 视觉升级：灰/深蓝高级复古风，替换荧光绿终端风
- 一键分析模板：预设场景一键发起分析
- 定时自动报告：按周期自动生成并落库
- 四个专业分析师角色：数据分析、经营财务、客户用户、营销增长
- 专业报告：在线交互报告 + 一键导出 PDF
- 图表扩展：漏斗图、雷达图、热力图等

## 技术选型理由

| 决策 | 理由 |
|------|------|
| FastAPI | 异步高性能，与 Python 数据生态无缝 |
| LangGraph | 原生支持循环图、Human-in-the-Loop 中断 |
| DeepSeek | 国内直连，支付宝充值，中文能力强 |
| SQLite | 零部署，与桌面应用天然契合 |
| React + AntD + ECharts | 成熟 UI 组件库，图表渲染能力强 |
| Electron | 跨平台打包，用户安装即用 |

## 约束条件
- 单用户桌面应用，无多租户
- 需要联网（LLM API 调用）
- 优先 Windows 10/11
- 数据文件需第一行为列名
