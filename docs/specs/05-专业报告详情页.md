# 阶段五 spec：专业报告详情页

## 目标

将保存的分析报告（summary / sections / charts / tables）以专业形式在线渲染，替代现有仅展示纯文本的 Modal 弹窗。

## 现状

1. 后端 /api/reports/{id} 已返回完整报告，字段齐全。
2. 前端 SchedulePage.tsx 已存在但未挂载到 App.tsx 路由，Sidebar 也缺「定时报告」入口。
3. 报告详情目前是 SchedulePage 内的 Modal，只展示 summary 纯文本，未渲染 charts、tables、sections。
4. 已可复用组件：ChartCard（渲染 echarts_option）、TableCard（渲染表格）、ReactMarkdown（渲染 summary）。

## 改动范围

1. App.tsx：新增 /reports 路由挂载 SchedulePage，新增 /reports/:id 路由挂载报告详情页。
2. Sidebar.tsx：主导航新增「定时报告」入口，指向 /reports。
3. 新建 pages/ReportDetailPage.tsx：拉取 /api/reports/:id，渲染标题、角色、状态、时间、sections 章节标签、summary（Markdown）、charts（ECharts）、tables（表格）。
4. SchedulePage.tsx：报告「查看」按钮由打开 Modal 改为跳转 /reports/:id，删除报告详情 Modal。

## 验收标准

1. 侧边栏出现「定时报告」，可进入定时任务与报告记录列表。
2. 点击报告「查看」跳转到独立详情页，正确渲染文字、图表与表格。
3. 空图表、空表格、失败状态报告均有合理兜底展示。
4. 前端 tsc --noEmit 通过，无类型错误。
