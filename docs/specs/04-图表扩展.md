# 阶段四 spec：图表类型扩展

## 目标

在既有 line / bar / pie / scatter / treemap / indicator 六种图表基础上，新增 funnel / radar / heatmap / waterfall 四种，覆盖三个角色的 chart_preferences 偏好，并供报告页复用。

## 角色偏好覆盖

1. data_analyst 偏好 line / bar / pie / scatter，均为既有能力。
2. operations_analyst 偏好 funnel / bar / line / pie / radar，其中 funnel 与 radar 为新增。
3. finance_analyst 偏好 indicator / bar / waterfall，其中 waterfall 为新增。

heatmap 不直接出现在角色偏好中，作为数据透视能力的通用补充，供交叉维度分析使用。

## 改动范围

1. backend/app/agent/tools/visualization.py：
   - 扩展 _PIE_LIKE 常量，加入 funnel / radar / waterfall，共享分类列推断与预处理逻辑。
   - 新增 _find_second_dimension，用于热力图 Y 轴推断。
   - 新增 _build_funnel_chart、_build_radar_chart、_build_heatmap_chart、_build_waterfall_chart。
   - 在 visualization 入口提前路由 heatmap，避免通用预处理干扰二维交叉表。
   - 更新分发逻辑与文档注释。

## 前端渲染确认

前端 ChartCard.tsx 直接渲染 echarts_option，不做 chart_type 分支。funnel / radar / heatmap 为 ECharts 原生类型，waterfall 以双堆叠柱状图（透明基底 + 增量柱）模拟，均无需前端改动。

## 验收标准

1. 后端四种新图表能生成合法 ECharts option，无 KeyError 或列推断失败。
2. 三个角色的 chart_preferences 所列图表均可在 visualization 中找到对应分支。
3. Python 语法与导入通过，pytest 无回归失败。
4. 前端 tsc --noEmit 通过，新图表类型无需前端适配。
