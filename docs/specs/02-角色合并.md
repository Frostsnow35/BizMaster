# 阶段二 spec：角色合并为三个

## 目标

把现有四个分析师角色收敛为三个，使其与确认后的需求一致。

## 角色映射

1. data_analyst 数据分析师，保持不变。
2. finance_analyst 财务经营分析师，由原「经营/财务分析师」改名而来。
3. operations_analyst 电商运营专家，合并原「客户/用户分析师」与「营销/增长分析师」。

## 改动范围

1. agent/roles.py：删除 customer_analyst 与 marketing_analyst，新增 operations_analyst，合并其 persona、planner_hint、chart_preferences、report_structure、keywords；修改 finance_analyst 名称与文档注释。
2. agent/templates.py：把 customer_profile、rfm_segmentation、channel_conversion、repurchase_churn、growth_opportunity 的 role_key 改为 operations_analyst。
3. agent/state.py：更新 role_key 字段的注释。
4. 前端 ChatContainer.tsx 与 SchedulePage.tsx 的角色下拉，同步为三个角色。

## 验收标准

1. 后端仅存在三个角色键，模板与前端下拉一致。
2. 推理与解析逻辑对未知角色键仍回退到 data_analyst。
3. 无残留 customer_analyst 或 marketing_analyst 引用。
