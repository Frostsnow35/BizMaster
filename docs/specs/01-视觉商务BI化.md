# 阶段一 spec：视觉商务 BI 化

## 目标

把现有「灰/深蓝高级复古风」升级为「深色商务 BI 风」，核心是去掉复古终端元素，引入金银点缀与中性克制阴影，让界面更接近专业 BI 工具。

## 设计决策

1. 主色保留专业蓝 #3b82f6，保持深蓝灰底色不变。
2. 强调色从复古琥珀 #f59e0b 改为金属金 #d4af37，作为金银质感中的金。
3. 银用在中性次要文字与边框，取值 #9aa7b5 到 #6b7686 区间。
4. 移除三类复古元素：CRT 扫描线 overlay、蓝色辉光文字、终端光标闪烁。
5. 阴影从蓝色辉光描边改为中性克制阴影。

## 改动范围

1. styles/global.css：重写 CSS 变量与 Ant Design 覆盖，删除 crt-overlay、glow-text、terminal-cursor。
2. App.tsx：删除 crt-overlay 节点，背景色对齐新变量。
3. Layout/Sidebar.tsx：去掉 glow-text，品牌区改用金色点缀。
4. Layout/Header.tsx：版本标签改为金银质感，文字色对齐。
5. Layout/Logo.tsx：琥珀星芒改为金色。
6. Chat/ChartCard.tsx 与 Chat/TableCard.tsx：卡片背景与阴影改为中性克制。

## 验收标准

1. 界面无 CRT 扫描线、无文字辉光、无终端光标闪烁。
2. 强调色为金色，次要色为银色灰。
3. 卡片阴影为中性灰，无蓝色辉光描边。
4. 前端 tsc 无新增类型错误。
