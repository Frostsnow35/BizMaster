# 提问指南与测试计划（Test Plan）

> 适用版本：ecommerce-data-agent R5+
> 本文档从**使用者的视角**出发：告诉你「可以用这个系统问什么问题」，每个问题附预期结果与验证要点。

---

## 0. 开始之前

1. 启动服务：
   ```powershell
   # 终端1：后端
   cd e:\自我学习项目\agent\ecommerce-data-agent\backend
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8002
   # 终端2：前端
   cd e:\自我学习项目\agent\ecommerce-data-agent\frontend
   npm run dev
   ```
2. 浏览器打开 `http://localhost:5173`，到「设置」页填入 DeepSeek API Key 并测试连接。
3. 到「数据管理」页上传 `sample-data/` 下的三份数据：
   - `orders.csv`（订单，600行）
   - `products.csv`（商品）
   - `customers.csv`（客户）
4. 到「对话」页，**先选择数据源，再提问**。

> 一句话规则：你的问题要基于所选数据源来问。选 orders 问销售，选 customers 问客户，选 products 问商品。

## 1. 订单/销售分析（选择 orders.csv）

| #  | 你可以这样问             | 预期结果                           | 验证要点                                 |
| -- | ------------------------ | ---------------------------------- | ---------------------------------------- |
| 1  | 本月销售额趋势如何？     | 生成按日/月汇总的折线图 + 趋势说明 | 图表是否按月展示，数值与表内实付金额一致 |
| 2  | 各品类销售额占比是多少？ | 饼图/柱状图 + 排名结论             | 占比合计约100%，Top 品类标注             |
| 3  | 哪些商品卖得最好？       | 表格（Top N 商品 + 销量/销售额）   | 排名表格式输出，数据可核对               |
| 4  | 各销售渠道的业绩对比？   | 柱状图 + 对比结论                  | 渠道分组正确（抖音小店/天猫旗舰店等）    |
| 5  | 哪个城市订单最多？       | 表格/柱状图 + 城市排名             | 城市列分组统计正确                       |
| 6  | 客单价是多少？           | 要点/单数值（实付金额 ÷ 订单数）  | 数值可自行验算                           |
| 7  | 哪几种支付方式使用最多？ | 表格/占比图                        | 支付方式分组正确                         |
| 8  | 近30天每日订单量是多少？ | 折线图 + 日均/峰值说明             | 日期过滤范围正确                         |
| 9  | 毛利率是多少？（成本列） | 要点/表格（(实付-成本)/实付）      | 计算结果与手工验算一致                   |
| 10 | 帮我预览一下数据         | 数据表格（前几行）+ 字段说明       | 列名与 orders.csv 表头一致               |

## 5. 结果处理（问完之后）

| 操作       | 怎么做                              | 预期结果                              |
| ---------- | ----------------------------------- | ------------------------------------- |
| 换格式     | 点回答底部的「要点/表格/报告/图表」 | 基于同一结果重新组织输出，按钮高亮    |
| 下载报告   | 点「下载报告 (.md)」                | 下载 Markdown 文件                    |
| 下载数据   | 点输入区旁的下载图标                | 下载 JSON（含问题、回答、图表、表格） |
| 看思考过程 | 点回答上方的「思考过程（N步）」     | 展开看到规划/执行/校验步骤            |

## 6. 问不出来 / 会失败的问题（重要！）

这部分**不是 Bug**，而是当前系统的边界。系统会明确告诉你原因，而不是编造答案。

| # | 你会这样问                       | 会发生什么  | 预期回答要点                                                    |
| - | -------------------------------- | ----------- | --------------------------------------------------------------- |
| 1 | 选 products 表问「本月销售额」   | 失败        | 指出商品表没有订单/金额字段，建议上传订单数据                   |
| 2 | 问「GMV」但表里没有 gmv 列       | 失败        | 指出缺少 gmv 字段，列出现有字段，给出替代计算建议（如实付金额） |
| 3 | 查询超出数据范围的时间           | 返回空      | 说明数据覆盖范围，提示查询不在范围内                            |
| 4 | 问「客户复购率」但只有单表       | 失败/不完整 | 说明单表无法关联客户与订单，建议上传订单表                      |
| 5 | 跨表问题：「哪个品类的客户最多」 | 失败/不完整 | 说明当前仅支持单数据源分析                                      |
| 6 | 未选择数据源就发送               | 无法发送    | 发送按钮禁用，提示先选数据源                                    |
| 7 | 未配置 API Key 就发送            | 报错        | 提示先到设置页配置 Key                                          |
| 8 | 后端未启动                       | 报错        | 提示无法连接到分析服务                                          |

**验证要点**：以上每种失败场景，AI 的回答必须给出「具体原因 + 可操作建议」，不能只说"可能的原因有..."。

## 7. 回归检查清单（每轮提问前快速过一遍）

- [ ] WebSocket 连接正常（无 403）
- [ ] 发送后先出现「思考过程」折叠框，再出现最终结论（顺序正确）
- [ ] 回答完成后思考框自动收起
- [ ] 回答底部有格式切换按钮，当前格式高亮
- [ ] 思考过程包含「规划 / 执行 / 校验」步骤
- [ ] 数据源用途标签正确（orders=订单/销售、products=商品、customers=客户）

---

## 8. 建议测试路径（10分钟走完）

1. 上传 3 份样本数据 → 检查类型标签
2. 选 orders 问「各品类销售额占比是多少？」→ 验证图表 + 思考过程 + 格式切换
3. 选 customers 问「客户画像分析」→ 验证报告格式
4. 点「表格」切换 → 验证重新生成
5. 选 products 问「本月销售额」→ 验证系统给出缺字段说明（不编造）
6. 点「下载报告」→ 验证文件下载
